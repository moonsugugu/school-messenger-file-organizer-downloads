# 딸깍정리 공개 배포

딸깍정리 통합 정리기와 딸깍정리 위젯의 설치 파일을 공개 배포하는 저장소입니다.
소스코드는 별도 비공개 저장소에서 관리합니다.

## 다운로드

- [딸깍정리 통합 정리기 v1.03 설치파일](https://github.com/moonsugugu/school-messenger-file-organizer-downloads/releases/download/organizer-v1.03/SchoolMessengerFileOrganizer_Setup-v1.03.exe)
- [딸깍정리 위젯 v1.11 설치파일](https://github.com/moonsugugu/school-messenger-file-organizer-downloads/releases/download/v1.11/DesktopOrganizerWidget_Setup.exe)
- [딸깍정리 위젯 v1.11 무설치 실행 ZIP](https://github.com/moonsugugu/school-messenger-file-organizer-downloads/releases/download/v1.11/DesktopOrganizerWidget-v1.11.zip)

앱은 공개 매니페스트를 확인해 새 버전이 있으면 업데이트 여부를 안내합니다.

구버전 업데이트에서 발생할 수 있는 실행 오류를 v1.11/v1.03에서 보완했습니다.
