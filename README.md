# 딸깍정리 공개 배포

딸깍정리 통합 정리기와 딸깍정리 위젯의 설치 파일을 공개 배포하는 저장소입니다.
소스코드는 별도 비공개 저장소에서 관리합니다.

- [딸깍정리 통합 정리기 설치파일](https://github.com/moonsugugu/school-messenger-file-organizer-downloads/releases/download/v1.01/SchoolMessengerFileOrganizer_Setup.exe)
- [딸깍정리 위젯 설치파일](https://github.com/moonsugugu/school-messenger-file-organizer-downloads/releases/download/v1.01/DesktopOrganizerWidget_Setup.exe)
- [딸깍정리 위젯 무설치 실행 ZIP](https://github.com/moonsugugu/school-messenger-file-organizer-downloads/releases/download/v1.01/DesktopOrganizerWidget-v1.01.zip)
