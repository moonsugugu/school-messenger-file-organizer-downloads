# 딸깍정리 공개 배포

딸깍정리 통합 정리기와 딸깍정리 위젯의 설치 파일을 공개 배포하는 저장소입니다.
소스코드는 별도 비공개 저장소에서 관리합니다.

## 다운로드

- [딸깍정리 통합 정리기 v1.04 설치파일](https://github.com/moonsugugu/school-messenger-file-organizer-downloads/releases/download/organizer-v1.04/SchoolMessengerFileOrganizer_Setup-v1.04.exe)
- [딸깍정리 위젯 v1.12 설치파일](https://github.com/moonsugugu/school-messenger-file-organizer-downloads/releases/download/v1.12/DesktopOrganizerWidget_Setup-v1.12.exe)
- [딸깍정리 위젯 v1.12 무설치 실행 ZIP](https://github.com/moonsugugu/school-messenger-file-organizer-downloads/releases/download/v1.12/DesktopOrganizerWidget-v1.12.zip)

앱은 공개 매니페스트를 확인해 새 버전이 있으면 업데이트 여부를 안내합니다.
설정 → 기본 설정에서 수동 업데이트 확인과 위젯 삭제를 실행할 수 있습니다.
위젯 삭제는 실행파일·아이콘·바로가기·자동실행 등록만 제거하며, 정리함·정리된 파일·규칙·설정은 보존합니다.
